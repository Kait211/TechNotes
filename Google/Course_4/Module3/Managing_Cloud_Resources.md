# Cloud Services and Cloud Computing

## Three Main Cloud Services

**Software as a Service (SaaS):** Software accessed through the internet without needing to install it on your device. Example: Gmail.

**Platform as a Service (PaaS):** A cloud platform used to develop and run applications without managing the underlying hardware.

**Infrastructure as a Service (IaaS):** Provides cloud-based IT resources like virtual machines, networks, and storage instead of buying physical hardware.

## Additional Cloud Services

**VPN as a Service (VPNaaS):** Provides a cloud-based VPN connection to securely connect users to an organization's network.

**Function as a Service (FaaS):** Runs small pieces of code in the cloud when triggered by an event, without needing to manage servers.

**Data as a Service (DaaS):** Provides access to data from different sources when needed, often through APIs.

**Blockchain as a Service (BaaS):** Provides cloud-based tools for using blockchain technology to store and manage connected, encrypted records.

## Four Types of Cloud Computing

**Public Cloud:** Cloud services provided by a company, such as Google Cloud or AWS, that are shared by multiple customers.

**Private Cloud:** Cloud environment dedicated to one organization, offering more control over its resources.

**Multicloud:** Using cloud services from multiple providers, such as Google Cloud and AWS.

**Hybrid Cloud:** Combines private and public cloud environments connected so they can work together.

## Remember

- **SaaS:** Use software.
- **PaaS:** Build applications.
- **IaaS:** Rent IT infrastructure.
- **VPNaaS:** Connect securely to a network.
- **FaaS:** Run code when triggered.
- **DaaS:** Access data.
- **BaaS:** Use blockchain technology.
- **Public Cloud:** Shared provider infrastructure.
- **Private Cloud:** One organization's cloud.
- **Multicloud:** Multiple cloud providers.
- **Hybrid Cloud:** Public and private clouds working together.

Most cloud providers offer free trials, so it's a good idea to test that out to see if they meet your needs, and to check how well you company's infrastructure integrates with the cloud providers

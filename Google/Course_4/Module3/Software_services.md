### Hyper text transfer protocol secure (HTTPS)
The secure version of HTTP, which makes sure the communication your web browser has with the website is secured through encryption

**SSL (Secure Sockets Layer):** An older security protocol that encrypts data. It is outdated and insecure.

**TLS (Transport Layer Security):** A newer, more secure protocol that encrypts data sent between devices and servers. It replaces SSL.

The main difference is TLS is newer and more secure than SSL

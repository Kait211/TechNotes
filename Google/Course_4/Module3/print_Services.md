## Printer Management

- **Printer Control Language (PCL):** A printing language that depends on the specific printer.
- **PostScript:** A printing language that works independently of the printer model.
- **Printer Configuration:** Settings like page orientation, print quality, paper tray, and duplex (printing on both sides).
- **Network Printer:** A printer connected to a network so multiple users can share it.
- **Network Scan Services:** Allows a printer to scan documents and send files to a network location, cloud storage, or email.
- **Printer Security:** Features that protect printers and track usage, such as user authentication, badges, secure printing, and audit logs.

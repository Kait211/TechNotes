# Glossary

**Autoscaling:** Automatically increases or decreases capacity as needed, so you only pay for the resources you use.

**Databases:** Store, search, filter, and manage large amounts of data.

**File Storage Service:** Allows files to be stored in one central location and access to be managed between users and groups.

**HTTPS:** Hypertext Transfer Protocol Secure. A secure version of HTTP that encrypts communication between a web browser and a website.

**HTTP Status Code:** A number that tells you the result of an HTTP request, such as success or an error.

**Hybrid Cloud:** Combines private and public clouds so companies can keep sensitive data private while using public cloud services for other tasks.

**Load Balancer:** Distributes network traffic across multiple servers or virtual machines to prevent any one server from becoming overloaded.

**Network File System (NFS):** A protocol that allows files to be accessed and shared over a network.

**Platform Services (PaaS):** Provides developers with a platform to build and deploy applications without managing the underlying hardware or operating systems.

**Private Cloud:** A cloud environment dedicated to one organization, hosted on-site or in a remote data center.

**Public Cloud:** Cloud services provided by a third-party company, such as Google Cloud or AWS.

**Regions:** Geographical areas containing one or more data centers.

**Software Services:** Applications employees use to perform daily tasks, such as web browsers, email clients, word processors, and chat applications.

**Web Server:** Software or a computer that stores and delivers website content to clients over the internet.

### Security Glossary

**Adware:** Software that displays advertisements and collects data.

**Attack:** An actual attempt at causing harm to a system.

**Availability:** Means that information is readily accessible to the people who should have access to it.

**Backdoor:** A secret way to access a system when normal entry methods are not available.

**Baiting:** An attack that uses physical items or enticing offers to trick a victim into doing something.

**Botnet:** A collection of one or more bots.

**Bots:** Machines compromised by malware that perform tasks controlled by an attacker.

**Brute Force Attack:** A common password attack that continuously tries different combinations of characters and letters until it gains access.

**CIA Triad:** Confidentiality, integrity, and availability. Three key principles used when designing information security policies.

**Confidentiality:** Keeping information private and hidden from unauthorized people.

**Cross-Site Scripting (XSS):** A type of injection attack where an attacker inserts malicious code that targets users of a service.

**Denial-of-Service (DoS) Attack:** An attack that prevents legitimate users from accessing a service by overwhelming a network or server.

**Dictionary Attack:** A password attack that tries commonly used passwords, such as password, monkey, or football.

**Distributed Denial-of-Service (DDoS) Attack:** A DoS attack that uses multiple systems to overwhelm a target.

**DNS Cache Poisoning Attack:** An attack that tricks a DNS server into accepting fake DNS records that redirect users to malicious websites.

**Evil Twin:** An attack where someone creates a fake Wi-Fi network that looks identical to a legitimate one to monitor user traffic.

**Exploit:** Software or code used to take advantage of a security bug or vulnerability.

**Hacker:** Someone who attempts to break into or exploit a system.

**Half-Open Attack:** Another term for a SYN flood attack.

**Injection Attack:** A security exploit where an attacker inserts malicious code or commands into a program or system.

**Integrity:** Keeping data accurate and protected from unauthorized changes.

**Keylogger:** A type of spyware that records every keystroke a user makes.

**Logic Bomb:** A type of malware that is intentionally installed and activates when a specific event or condition occurs.

**Malware:** Malicious software used to steal sensitive information, delete files, or modify data.

**Meddler-in-the-Middle (formerly Man-in-the-Middle):** An attack where someone secretly places themselves between two hosts that believe they are communicating directly.

**Password Attacks:** Attacks that use software or techniques to guess or crack passwords.

**Phishing Attack:** An attack where a malicious email is disguised as something legitimate to trick someone into revealing information or clicking a link.

**Ping Flood:** An attack that sends large amounts of ping packets to overwhelm a computer or network.

**Ransomware:** Malware that holds your data or system hostage until you pay a ransom.

**Risk:** The possibility of suffering a loss as a result of an attack on a system.

**Rogue Access Point (AP) Attack:** An unauthorized access point installed on a network without the administrator's knowledge.

**Rootkit:** A type of malware that hides itself and allows attackers to secretly access or control a system.

**Screen Lock:** A security feature that prevents unwanted access by requiring an action, such as entering a password, to unlock a device.

**Session Hijacking (Cookie Hijacking):** An attack where someone steals or takes over a user's active session to gain unauthorized access.

**Social Engineering:** An attack method that relies on tricking or manipulating people instead of directly attacking computers.

**Spear Phishing:** A type of phishing that targets a specific person or group, often using personal information to make fake emails look legitimate.

**Spoofing:** When someone or something pretends to be another trusted source.

**Spyware:** A type of malware designed to secretly monitor or spy on a user.

**SQL Injection Attack:** An attack that inserts malicious SQL commands into a website to access or manipulate its database.

**SYN Flood:** An attack where a server is overwhelmed with SYN packets, preventing legitimate connections.

**Tailgating:** Gaining access to a restricted area by following an authorized employee inside.

**Threat:** A possible danger that could exploit a vulnerability.

**Trojan:** Malware that disguises itself as legitimate software but performs malicious actions.

**Viruses:** A type of malware that attaches itself to files or programs and spreads when they run.

**Vulnerability:** A weakness in a system that could be exploited by an attacker.

**Worms:** Malware similar to viruses, but worms can spread on their own without attaching themselves to another file or program.

**0-Day Vulnerability (Zero-Day):** A vulnerability that is unknown to the software developer or vendor but may be known to an attacker.

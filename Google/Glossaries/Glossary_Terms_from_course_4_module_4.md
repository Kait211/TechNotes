# Course 4, Module 4 Glossary

**AAA (Authentication, Authorization, Accounting):** Services that directory services provide to computers within an organization.

**Active Directory (AD):** Microsoft's directory service that offers customization and added features for Windows.

**Active Directory Users and Computers (ADUC):** Client tools used to access and administer a directory server.

**Advanced Group Policy Management (AGPM):** Microsoft add-on tools that provide additional version control abilities in GPMC.

**Bind Operation:** An operation that authenticates clients to the directory server.

**Central Management:** A central service that provides instructions to different parts of an IT infrastructure.

**Change Management Process:** The process of notifying others in an organization about upcoming changes.

**Computer Configuration:** Settings contained within a Group Policy Object (GPO) that control computer settings.

**Configuration Management:** Creating rules for how things should work in an organization, such as printers, software, and network file systems.

**Default Domain Controller Policy:** One of the two GPOs created when a new Active Directory domain is created.

**Delegation:** Assigning administrative tasks to users without giving them full access to Active Directory.

**Directory Access Protocol (DAP):** A protocol included in the X.500 directory standard from 1988.

**Directory Information Shadowing Protocol (DISP):** A protocol included in the X.500 directory standard from 1988.

**Directory Operational Bindings Management Protocol (DOBMP):** A protocol included in the X.500 directory standard from 1988.

**Directory Server:** A server that contains a lookup service that maps network resources to their network addresses.

**Directory Services:** A lookup service that maps network resources to their network addresses.

**Directory System Protocol (DSP):** A protocol included in the X.500 directory standard from 1988.

**Distribution Group:** A group designed to organize accounts and contacts for email communication.

**DNS Records:** Records used to identify services and their locations on a network.

**Domain Admin:** Administrators of an Active Directory domain.

**Domain Computers:** All computers joined to a domain, except domain controllers.

**Domain Controllers (DC):** Servers that host copies of the Active Directory database.

**Domain Local:** A group scope used to assign permissions to resources.

**Domain Users:** A group containing every user account in the domain.

**Enterprise Admin:** Administrators who can make changes that affect multiple domains within an Active Directory forest.

**Enterprise Mobility Management (EMM):** A system that creates and distributes policies and mobile device management settings.

**Fast Logon Optimization:** A Group Policy feature that can delay certain policies to make user logins faster.

**Flexible Single-Master Operations (FSMO):** Special Active Directory roles that allow specific changes to be handled by one designated domain controller at a time.

**Forest:** A hierarchy containing multiple Active Directory domains that can share resources.

**Functional Levels:** Active Directory versions that determine which features are supported.

**Global:** A group scope used to organize accounts by role.

**Group Policy Management Console (GPMC):** A tool used to create, manage, and view Group Policy Objects.

**Group Policy Objects (GPO):** Collections of settings used to manage Windows computers and users.

**Group Policy Settings Reference:** A spreadsheet that lists available GPO policies and preferences and where to find them.

**Group Scope:** Determines how groups are used and which domains they can access resources in.

**Import:** Moving a backup of a test policy into a production policy.

**Kerberos:** A network authentication protocol that uses tickets to verify identities securely.

**LDAP Data Interchange Format (LDIF):** A format used to add, remove, and modify directory information such as users, groups, and computers.

**LDAP Entry:** A collection of information used to describe something in a directory.

**LDIF Files:** Text files containing attributes and values that describe directory entries.

**Lightweight Directory Access Protocol (LDAP):** An open industry-standard protocol for accessing and managing directory services.

**Linked:** A GPO connected to a domain, site, or OU so its policies can apply to the users and computers within it.

**MDM Policy:** Rules that control settings on a mobile device.

**MDM Profile:** A collection of settings applied to a mobile device.

**One-Way Cryptographic Hash:** A method Active Directory uses to securely store password information.

**OpenLDAP:** A free, open-source directory service that uses LDAP.

**Organizational Units (OU):** Containers in Active Directory that organize users, computers, groups, and other OUs.

**Parent Group:** A group that contains other groups.

**PHPLDAPadmin:** A tool used to manage OpenLDAP.

**Policies:** Settings that are regularly reapplied and are not meant to be changed by local administrators.

**Precedence:** The order in which Group Policy settings are applied. Later policies can override earlier ones.

**Read-Write Replicas:** Domain controllers that have a complete copy of the Active Directory database and can make changes to it.

**Remote Wipe:** A factory reset that can be triggered remotely through a central MDM system.

**Replication:** Copying directory data across multiple servers so it appears as one unified directory.

**Replication Failure:** A problem that can prevent directory data or GPO changes from being properly distributed.

**Reset:** When a system administrator restores or changes a user's password.

**Restart:** A command that reboots a computer, sometimes needed to complete a domain join.

**Resultant Set of Policy (RSOP):** The final collection of Group Policy settings applied to a specific computer or user.

**Role-Based Access Control (RBAC):** Assigning access permissions based on a person's job role.

**RSOP Report:** A report used to troubleshoot Group Policy by showing which policies are actually applied.

**Security Account Manager (SAM):** A Windows database that stores local user account and password information.

**Security Filtering:** A feature that controls which users and computers receive a GPO.

**Security Group:** A group in Active Directory that can contain users, computers, and other security groups to manage permissions.

**Security Principal:** An entity that can be authenticated, such as a user account or computer account.

**Service Discovery:** A service that helps clients locate services provided by a domain controller.

**Simple Authentication and Security Layer (SASL):** An authentication framework that allows clients and directory servers to authenticate using different security methods.

**SRV Records:** DNS records that identify the location of specific network services.

**Systems Administrator (Sysadmin):** A person responsible for managing servers, networks, user accounts, and computer systems.

**Universal:** A group scope used to organize global groups across an Active Directory forest.

**User Configuration:** Settings within a GPO that control user-specific Windows settings.

**User Groups:** Groups of user accounts organized to manage access to computer and network resources.

**Windows Management Instrumentation (WMI):** A Windows management tool that provides information about computers and helps create targeting rules for GPOs.

**Windows Registry:** A hierarchical database where Windows and applications store configuration settings.

**WMI Filter:** A tool that makes GPOs apply selectively based on computer conditions.

**Workgroup Computer:** A Windows computer that is not joined to an Active Directory domain.

**X.500 Directory:** A directory standard approved in 1988 that defines protocols for accessing and managing directory information.

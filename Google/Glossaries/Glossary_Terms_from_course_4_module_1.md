### New Terms and Their Definitions

**Cloud Computing:** Accessing data, applications, and storage over the internet from almost anywhere.

**Data Center:** A facility that houses many servers and other computing equipment.

**Deployment:** Setting up hardware and software so an employee can do their job.

**IT Infrastructure:** The hardware, software, networks, and services an organization needs to operate.

**KVM Switch:** A device that lets you control multiple computers using one keyboard, monitor, and mouse.

**Maintenance:** Updating software and fixing hardware problems to keep systems working properly.

**Procurement:** Purchasing or acquiring hardware for employees or an organization.

**Production:** The environment where systems and services run and are used by actual users.

**Reproduction Case:** Recreating an error to test a solution and verify that a fix works.

**Retirement:** Properly removing hardware from use when it is no longer needed or usable.

**Rollback:** Reverting a system or configuration to its previous state after a change.

**Secondary or Standby Machine:** A backup machine that can take over for a production machine when needed.

**Server:** A computer or software that provides services or resources to other computers or programs.

**System Administration:** The field of IT responsible for maintaining reliable computer systems, especially in multi-user environments.

**Test Environment:** An environment that replicates a production setup for testing changes without affecting actual users.

# Glossary

**App Store apps:** A package manager that acts as a repository.

**App Store repository:** An app store service that also acts as a repository.

**App stores:** A central, managed marketplace for app developers to publish and sell mobile apps.

**APPX:** An APPX is another way to package the contents of a file so they can act as a unit of distribution.

**Archive:** An archive is comprised of one or more files that are compressed into a single file.

**Block devices:** A system that acts like USB drives and hard drives by transmitting data in blocks.

**Cache:** An assigned storage location for recently or frequently accessed data; on a mobile app, it is where anything that was changed or created with that app is stored.

**Character devices:** A way to transmit data character by character, like with a keyboard and mouse.

**Chocolatey:** A third-party package manager for Windows.

**Closed source packages:** Packages whose source code does not allow public access.

**Debian (.deb):** A Debian package is packaged as a `.deb` file.

**Device manager:** A console management system for your device.

**Driver:** Software used to help hardware devices interact with the operating system.

**Dynamic-link libraries:** Shared libraries that allow programs to use functionality provided by the library when they need it.

**Enterprise app management:** A management system that allows an organization to distribute custom mobile apps.

**Executable file:** A file containing instructions for a computer to execute when it is run.

**Hardware ID:** A special string of characters assigned to hardware.

**Having dependencies:** A process of relying on other pieces of software to make an application work because one piece of code depends on another.

**Installing from source:** A process of installing software directly from its source code.

**Kernel module:** A component that extends the kernel's functionality so developers do not have to modify the Linux kernel itself.

**Library:** A way to package a collection of useful code that someone else has written.

**Manifest:** A file used to describe an application's contents and requirements, such as the shared libraries it needs to use.

**Microsoft Install Package (.msi) and MSI files:** A Microsoft Install Package is a file extension used by Windows Installer to guide the installation, maintenance, and removal of programs on Windows operating systems. MSI files are a combination of databases that contain installation instructions in different tables, along with the files needed for the installation.

**Mobile applications:** Software that is distributed on mobile operating system devices.

**Packaged archives:** Core or source software files that are compressed into a single file.

**Package managers:** Applications that make package installation and removal easier.

**Personal package archives:** Software repositories used for uploading source packages to be built and published.

**Portable Executable (PE) format:** Windows' unique version of the executable file format.

**Process monitoring:** A way of monitoring what processes are happening during an installation.

**Repository:** A server that acts as a central storage location for packages.

**SD devices:** Mass storage devices, such as hard drives.

**Security patch:** A piece of software that is meant to fix a security vulnerability.

**Side-by-side assemblies:** A system that manages most shared libraries and resources on Windows and supports access to multiple versions of the same shared library automatically.

**Side-loading:** A process of installing mobile apps directly without using an app store.

**Sysinternals package:** A set of tools released by Microsoft that can help you troubleshoot and diagnose problems.

**Windows Store:** A Windows application repository or warehouse where you can download and install Universal Windows Platform apps.

**Windows Update Client Service:** A system that runs in the background on your computer to download and install updates and patches for the operating system.

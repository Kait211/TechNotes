**Domain Name System (DNS):** A global network service that translates website names into IP addresses.

**Intranet:** An internal network inside a company that is accessible to people connected to the company's network.

**NTP (Network Time Protocol):** Keeps clocks synchronized on computers and devices connected to a network.

**Proxy Server:** An intermediary between a company's network and the internet that receives and forwards network traffic.

**Server Operating Systems:** Operating systems optimized to run and manage servers.

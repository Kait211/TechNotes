**Activation Threshold:** Triggers a pre-configured action when reached, typically blocking identified attack traffic for a specific amount of time.

**Analyzing Logs:** Collecting logs from network devices and analyzing them to identify unusual activity.

**CCMP (Counter Mode CBC-MAC Protocol):** A mode of operation for block ciphers that provides authenticated encryption.

**Correlation Analysis:** Matching log events from different systems to identify related activity.

**Dynamic ARP Inspection (DAI):** A feature on enterprise switches that prevents certain types of ARP attacks.

**EAP-TLS:** A common and secure EAP authentication method that uses certificates.

**Extensible Authentication Protocol (EAP/EAPOL):** A standard authentication protocol used for network access.

**Fail2ban:** An open-source tool that protects against repeated failed login attempts by blocking suspicious IP addresses.

**Flood Guards:** Provide protection against DoS (Denial of Service) attacks.

**Four-Way Handshake:** Allows an access point to verify that a client has the correct PMK without revealing the PMK.

**GTK (Group Temporal Key):** A temporary key used to encrypt wireless broadcast and multicast data.

**Hubs:** Devices that act as a central connection point for network devices. Can be used to mirror packets for capturing.

**Implicit Deny:** A security concept where anything not explicitly allowed is automatically denied.

**IDS/IPS (Intrusion Detection/Prevention Systems):** Monitor and analyze network traffic to identify or prevent suspicious activity.

**IP Source Guard (IPSG):** A feature on enterprise switches that helps prevent IP address spoofing. Works alongside DHCP snooping.

**Log Analysis Systems:** Use user-defined rules to identify unusual or interesting log entries.

**Monitor Mode:** Allows wireless adapters to capture traffic across wireless channels.

**Network Hardening:** Securing a network by reducing vulnerabilities through configuration changes and security measures.

**Network Separation (Network Segmentation):** Dividing a network into smaller virtual networks (VLANs) to improve security and management.

**Network Software Hardening:** Securing a network using tools like firewalls, proxies, and VPNs.

**OES (Operating Encounter Mode):** Turns a block cipher into a stream cipher using a random seed and an incrementing counter to create an encryption key stream.

**Packet Sniffing (Packet Capture):** Intercepting network packets for analysis.

**Pairwise Transient Key (PTK):** A temporary encryption key generated using the PMK, nonces, and MAC addresses of the access point and client.

**PBKDF2 (Password-Based Key Derivation Function 2):** A function that converts passwords into cryptographic keys.

**PIN Authentication Method:** Uses an eight-digit PIN, where the last digit is a checksum calculated from the first seven digits.

**Port Mirroring:** Allows a switch to copy network traffic from specified ports or VLANs to another port for monitoring.

**Post-Fail Analysis:** Investigating how a security breach happened after it has been detected.

**Pre-Shared Key (PSK):** A Wi-Fi password shared with users to allow them to connect to a wireless network.

**Promiscuous Mode:** Allows a network adapter to capture all packets it can see, not just packets addressed to it.

**Proxy:** Acts as an intermediary between clients and other systems. Can help protect client devices and provide secure remote access.

**Rainbow Tables:** Pre-computed tables containing password hashes used to help crack passwords.

**Reverse Proxy:** Acts as a single server to external clients while directing traffic to multiple servers behind it.

**Rogue DHCP Server Attack:** An attack where an unauthorized DHCP server provides clients with malicious network settings, such as a fake gateway or DNS server.

**Tcpdump:** A lightweight command-line tool used to capture and analyze network packets.

**TKIP (Temporal Key Integrity Protocol):** A security protocol introduced to address weaknesses in WEP.

**VPNs (Virtual Private Networks):** Provide secure remote access and securely connect separate networks.

**WEP (Wired Equivalent Privacy):** The first security protocol introduced for Wi-Fi networks. It is now considered insecure.

**Wireshark:** A packet capture and analysis tool with powerful graphical features for examining network traffic.

**WPA (Wi-Fi Protected Access):** A temporary replacement for WEP designed to work with older hardware through firmware updates.

**WPA2 Enterprise:** Uses 802.1X authentication to control access to Wi-Fi networks.

**WPS (Wi-Fi Protected Setup):** A convenience feature designed to make connecting to WPA-PSK networks easier.

**802.1X:** An IEEE standard for network access control that uses EAP authentication.

**802.1X with EAP-TLS:** A highly secure authentication method that uses certificates for network access.

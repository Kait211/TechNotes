### Package manger
Makes sure that the process of software installation, removal, update, and dependency management is as easy and automatic as possible 

- APT stands for Advanced Package Tool

# An example of how to install/remove a package in ubuntu CLI
```
sudo apt install gimp

sudo apt remove gimp
```
- Repositories are servers that act like a central storage location for packages

- The repository source file in Ubuntu is /ect/apt/sources.list

### if packages are out of date 
- apt update
- apt upgrade 

# It is considered good practice to update before installing
sudo apt update
sudo apt install package-name

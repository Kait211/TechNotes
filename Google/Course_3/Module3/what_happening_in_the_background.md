### Closed Source Packages
Packages where you can't look at the source code to see what the program is doing

## MSI

**MSI** stands for **Microsoft Installer** (more precisely, **Windows Installer**).

In simple terms:

> **An `.msi` file is a Windows installation package.**

It contains the information and files needed to **install a program on Windows**.

### Easy comparison

- **`.exe`** → Windows program/executable
- **`.msi`** → Windows **installer package**
- **`.deb`** → Linux/Ubuntu **package**
- **`.zip`** → Compressed **archive**

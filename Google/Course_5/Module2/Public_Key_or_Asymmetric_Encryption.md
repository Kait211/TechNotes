Asymmetric encryption systems use different keys to encrypt and decrypt

# Three concepts that an asymmetric crypto system grants us are...
- Confidentiality
- Authenticity
- Non-repudiation

### MAC
A bit of information that allows authentication of a received message, ensuring that the message came from the alleged sender and not a third party masquerading as them

### HMAC
Keyed-hashed message authentication code

### CMACs
Ciper-Based message authentication codes

### CBC-MAC
Cipher block chaining message authentication codes 

### Elliptic curve cryptography (ECC)
A public keu encryption system that uses algebraic structure of elliptic curves over finite fields to generate secure keys

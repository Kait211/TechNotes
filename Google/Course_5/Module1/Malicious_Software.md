### CIA 
C: Confidentiality
I: Integrity 
A: Availability 

### CIA triad
A guiding model for designing information security policies 

### Confidentiality
keeping things hidden

### Integrity
Keeping our data accurate and untempered with 

### Availability
The information we have is readily accessible to those people that should have it

### Risk
The possibility of suffering a loss in the event of an attack on the system 

### Vulnerability
A flaw in a system that could be exploited to compromise the system

### 0-day vulnerability (zero day)
A vulnerability that is not known to the software developer or vendor, but is known to an attacker 

### Exploit
Software that is used to take advantage of an security bug or vulnerability 

### Threat
The possibility of danger that could exploit a vulnerability 

### Hacker
A hacker in the security world is someone who attempts to break into or exploit a system

### Attack
An actual attempt at causing harm to a system

### Malware
A type of malicious software that can be used to obtain your sensitive information, or delete or modify files 

In a computer virus, the virus attaches itself to some sort of executable code like a program 

When the program is running, it touches many files, each of which is now susceptible to being infected with the virus 

Worms are similar to viruses except that instead of having to attach themselves onto something to spread, worms can live on their own and spread through channels like the network 

### Adware
Software that displays advertisements and collects data

### Trojan
Malware that disguises itself as one thing but does something else 

### Spyware
A type of malware that's meant to spy on you

### Keylogger
A common type of spyware that's used to record every keystroke you make 

### Ransomware
A type of attack that holds your data or system hostage until you pay some sort or ransom 

## Malware Detection and Removal

### 1. Gather and Verify
- Ask the user when the problems started.
- Ask if they downloaded any unusual files.
- Common signs of malware:
  - Slow computer performance.
  - Unexpected restarts.
  - Unusually high memory usage.
- Use **Resource Monitor** to check running processes.
- Investigate unfamiliar or suspicious programs.

### 2. Quarantine Malware
- **Quarantine:** Isolate an infected computer from the network.
- Turn off Wi-Fi and unplug the Ethernet cable.
- Prevents malware from spreading to other computers.
- Disable automatic backups to prevent restoring infected files.

### 3. Remove Malware
- Run an **offline malware scan** while disconnected from the network.
- Make sure antivirus threat definition files are updated.
- Scan, quarantine, and remove detected malware.
- Monitor the computer afterward to confirm the infection is gone.
- Enable automatic threat definition updates and scans.
- Turn automatic backups back on.
- Create a new, clean restore point.

### 4. Malware Prevention
- Keep computers and software updated.
- Use a non-administrator account when possible.
- Avoid suspicious links and downloads.
- Be careful with email attachments.
- Don't trust pop-ups asking you to download software.
- Limit file sharing.
- Use antivirus software.
- Educate employees about malware risks.

### Key Takeaways
- Detect malware by looking for unusual computer behavior.
- Isolate infected devices immediately.
- Use antivirus software to scan and remove malware.
- Keep threat definitions updated.
- Educating users is one of the best ways to prevent malware.

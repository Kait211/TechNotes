# The Three A's of Security
- Authentication
- Authorization
- Accounting 

### Identification
The idea of describing an entity uniquely 

Incorporating **good password policies** into an organization is key to ensuing that employees are securing their accounts with **strong passwords**

# A good password policy requirements would have...
- length requirements
- character complexity 
- check for dictionary words use since they are too easy to crack
- have password rotation 

### OTP (One-Time Password)
A password that can only be used once to authenticate a user or verify their identity.

### Multifactor authentication
A system where users are authenticated by presenting multiple pieces of information or objects 

### Biometric authentication
The process of using unique physiological characteristics of an individual to identify them 

In order to issue client certificates, an organization must setup and maintain CA infrastructure to issue and sign certificate 

### Certificate revocation list (CRL)
A singed list published by the CA which defines certificates that have been explicitly revoked 

### Remote authentication dial -in user service (RADIUS)
A protocol that provides AAA services for users on a network 

### Kerberos 
A network authentication protocol that uses "tickets" to allow entities to prove their identity over potentially insecure channels to provide mutual authentication 

The authentication tickets lets users authenticate to services without requiring username and password authentication for every service individually 

A ticket will expire after some time, but it has provisions for automatic transparent renewal of the ticket 

### TACACS+
Terminal Access Controller Access-Control System Plus

TACACS+ is primarily used for device administration, authentication, authorization, and accounting 

### Single sign-on (SSO)
An authentication concept that allows users to authenticate once to be granted access to a lot of different services and applications
